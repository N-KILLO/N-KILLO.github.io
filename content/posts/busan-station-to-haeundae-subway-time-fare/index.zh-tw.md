**46分鐘，刷交通卡1,800韓元。** 在釜山站（부산역）搭1號線往老圃（노포）方向，到西面站（서면역）轉2號線往萇山（장산）方向，轉一次就到海雲台站（해운대역）。從海雲台站5號出口走到海雲台海水浴場（해운대해수욕장）還要15分鐘，所以從釜山站的驗票閘門到沙灘，抓**1小時出頭**就可以了。（票價是2026/11/19、所需時間是11/9向釜山交通公社查證）

## 多久、多少錢：一張表看完

| 項目 | 內容 |
|---|---|
| 所需時間 | 46分鐘（含西面站轉乘2分鐘） |
| 搭車順序 | 1號線釜山站（往老圃方向）→ 西面站 → 2號線（往萇山方向）→ 海雲台站 |
| 距離、區間 | 20.1公里，2區間（超過10公里） |
| 成人 | 交通卡1,800韓元／QR車票1,900韓元 |
| 青少年（滿13～18歲） | 交通卡1,200韓元／QR車票1,300韓元 |
| 兒童（滿6～12歲） | 交通卡免費／QR車票800韓元 |
| 海雲台站 → 海水浴場 | 5號出口，步行15分鐘 |

兩個大人來回，刷交通卡是7,200韓元。沒有交通卡的話，在售票機買QR車票就好，只是每搭一趟要多付100韓元。搭的次數越多，交通卡越划算。

## 這幾種情況不一樣

- **一天搭四趟以上**：手機App的一日券是6,000韓元。2區間搭四趟是7,200韓元，從第四趟開始一日券比較便宜。這張只能搭地鐵，公車、東海線、輕軌都不能用。
- **晚上很晚才移動**：釜山站1號線老圃行末班車是23:49，西面站2號線萇山行末班車是00:00。照數字接得上，但很趕，23點前就離開釜山站吧。回程的話，海雲台站能到西面的末班車是23:29（湖浦行），更早。
- **搭首班車**：釜山站老圃行首班車是05:26。時刻表每天會依星期幾略有不同，清晨或末班車，搭車前再看一次站內的時刻表。

不想轉車，或是想跟公車、計程車比較的話，[釜山站到海雲台交通懶人包]({{< relref "/posts/busan-station-to-haeundae" >}})裡有1003號急行公車和計程車費。交通卡、一日券和轉乘規則，另外整理在[釜山地鐵搭乘指南]({{< relref "/posts/busan-metro-guide" >}})。

## 怎麼去

從釜山站的火車月台出來，往下走到地鐵1號線釜山站，搭**往老圃方向**的列車。在**西面站**下車，轉**2號線往萇山方向**，從**海雲台站5號出口**出去，走15分鐘左右就是海邊。
