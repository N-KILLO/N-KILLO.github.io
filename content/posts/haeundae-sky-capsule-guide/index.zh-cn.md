## 天空胶囊和海岸列车有什么区别

两者都在旧东海南部线的铁路上运营，运营方都是海云台蓝线公园（해운대블루라인파크）。按釜山观光公社的介绍，**海岸列车**是往返于尾浦、青沙浦、松亭4.8公里海岸线、"兼具交通功能的观光列车"；**天空胶囊**是在离地7–10米的轨道上自动行驶、连接尾浦和青沙浦2公里的体验设施。

- **天空胶囊**是只坐自己一行人的小胶囊，一车最多4人，只跑单程，只能在预约的车站（尾浦或青沙浦）上车。
- **海岸列车**是大家一起坐的列车，没有固定座位，可能要站着。买两次票或全站票，可以在中途小站（月见隧道、海月观景台、桥石观景台、九德浦）下车再上车。
- 官方套票是**天空胶囊单程＋海岸列车全站票**，设计思路就是去程坐胶囊、回程坐列车。

## 运行时间和末班（冬季11–2月）

### 天空胶囊入场时段

冬季（11、12、1、2月）胶囊时刻表是**每30分钟一档，共19档**。预约的时间是**可入场的时间段**，不是出发到到达的时间，在这30分钟内进场后按顺序乘坐。

| 档次 | 入场时间 |
|---|---|
| 第1档 | 08:30–09:00 |
| 第2–18档 | 从09:00起每30分钟一档 |
| 第19档（末班） | 17:30–18:00 |

过了最后入场时段就不能进。周末、节假日或检修时乘坐可能延后；比预约时间晚到30分钟以上，可能被拒绝乘坐且不退款。

## 尾浦出发还是青沙浦出发

| | 尾浦站（미포정거장） | 青沙浦站（청사포정거장） |
|---|---|---|
| 地址 | 海云台区月见路62街13 | 海云台区青沙浦路116 |
| 最近地铁 | 2号线**中洞站（중동역）7号出口**，约800米，步行10–15分钟 | 没有。社区巴士2、7、10路到"蓝线公园"站下车 |
| 从海云台海水浴场 | 就在沙滩东端 | 坐列车或胶囊过去 |
| 停车 | 蓝线公园尾浦停车场（塔式） | **没有专用停车场** |
| 胶囊方向 | 尾浦 → 青沙浦 | 青沙浦 → 尾浦 |

**大海在哪一侧？** 按官方路线图和地图，轨道沿海岸向东延伸，海在南侧。所以**从尾浦去青沙浦，海在行进方向右侧；从青沙浦回尾浦，海在左侧。** 太阳从西边（海云台海水浴场、Marine City高楼方向）落下，**想正对着看日落，走青沙浦 → 尾浦方向更合适**。这是从路线图推出来的一般性建议，不是官方推荐，座位朝向和实际视野要看天气和车厢。

## 往返路线：胶囊单程＋列车单程

直接照官方套票（胶囊单程＋列车全站票）的结构走就行。预约页面上选**出发地（尾浦、青沙浦、松亭）**和**先坐哪个**。

1. 在**尾浦站**坐天空胶囊，约30分钟后到**青沙浦站**。
2. 从青沙浦用全站票坐海岸列车去**桥石观景台、九德浦、松亭**，再折返回尾浦方向。全站票每站可以下车一次。
3. 反过来也行：从青沙浦坐胶囊回尾浦（套票里把胶囊上车点选成青沙浦）。

从松亭出发的话那里没有胶囊，官网说明要先选海岸列车。官网还提醒，胶囊排队太久到得晚，可能赶不上末班列车，所以傍晚的行程最好留点余地。

| 日期 | 釜山日落 |

| 11月30日 | 17:12 |
| 12月3–8日 | 17:11（全年最早） |
| 12月15日 | 17:13 |
| 12月24日 | 17:17 |

- 想在胶囊里看日落，订**16:30–17:00或17:00–17:30入场**这两档，正好对上日落（17:11–17:21）。单程约30分钟，进场后很快上车的话，太阳落山时你正在海面上方。
- **海岸列车日落后还开到19:00**，也可以安排一段看夜色海景的路线。
- 日落时间以地平线为准，月见岭一侧的地形和天气会影响实际看到的时间。

## 一般建议

只整理官网页面里有的内容。

- **记住周二早上7点（韩国时间）。** 4周后的一整周同时开票。想要哪一天，往前数4周的那个周二就是预约日。
- **天空胶囊是指定时间的票。** 迟到30分钟以上可能上不了车，也不退款。从海云台站到尾浦，公交加步行预留20分钟左右比较稳。
- **海岸列车只要守住第一次乘车时间。** 再次上车按到达顺序排队，青沙浦和各小站是先到先上，人多时要等。
- **行李放储物柜。** 尾浦、青沙浦、松亭都有储物柜（小2,000、中3,000、大5,000韩元）。登机箱可以带上车，大件行李可能被限制。
- **婴儿车折叠，宠物放航空箱。** 手动轮椅可直接上海岸列车，坐天空胶囊要折叠后移动；电动轮椅两种都不能乘。
- **尿布台**在尾浦站、青沙浦站二楼女洗手间和松亭站售票处前的女洗手间。
- **下雨照常运行**，暴雨、台风可能停运，出发前看一下公告。
- 胶囊内冷暖空调、座位朝向、平均等待时间，官网没有写明数字，本文不写。

## 常见问题

### 天空胶囊不预约能当天买吗？

售票处有少量当天票，先到先得，官网提醒可能提早售完。想保证能坐，就在周二7点开票时预约。

### 天空胶囊票价是每人吗？

不是，是**每车**。2人座50,000、3人座55,000、4人座60,000韩元，车厢内部大小都一样。

### 海岸列车往返多少钱？

单次票是单程，往返要买两次票（14,000韩元）或全站票（16,000韩元）。儿童分别是11,000和13,000韩元。

### 冬季末班几点？

天空胶囊最后入场时段是17:30–18:00。海岸列车尾浦、松亭出发末班19:00，青沙浦出发19:09（往松亭）、19:12（往尾浦），末班前10分钟停止售票。

### 从尾浦还是青沙浦上车好？

坐地铁方便的是尾浦（中洞站7号出口步行10–15分钟）。看日落的话，向西走的青沙浦 → 尾浦方向更正对（按路线图推断的一般建议）。

### 11月底到12月釜山几点日落？

按韩国天文研究院的数据，11月24日17:13，12月3–8日17:11，12月24日17:17，12月31日17:21。

### 釜山通票（Visit Busan Pass）能用吗？

这次没能从官方资料确认是否包含。请在[Visit Busan Pass官网](https://www.visitbusanpass.com/)的设施列表里直接查。

### 5个人能坐一辆胶囊吗？

基本上最多4人。只有其中1人是7岁以下（2020年及以后出生）的5人可以坐4人座，否则要分成2人座＋3人座。
