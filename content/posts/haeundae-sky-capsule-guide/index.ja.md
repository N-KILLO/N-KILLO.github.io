## スカイカプセルと海辺列車、何が違う？

どちらも旧東海南部線の線路跡を使い、運営は海雲台ブルーラインパーク（해운대블루라인파크）です。釜山観光公社の説明では、**海辺列車**は尾浦〜青沙浦〜松亭の4.8kmを往復する「交通手段を兼ねた観光列車」、**スカイカプセル**は地上7〜10mのレールの上を尾浦〜青沙浦の2km自動で走る体験施設、とのことです。

- **スカイカプセル**は自分たちのグループだけで乗る小さなカプセル。1台最大4人、片道のみ。予約した駅（尾浦か青沙浦）からしか乗れません。
- **海辺列車**は相乗りの列車。指定席がないので立つこともあります。2回券か全駅券なら、途中の簡易駅（タルマジトンネル、海月展望台、タリットル展望台、九徳浦）で降りてまた乗れます。
- 公式パッケージは**スカイカプセル片道＋海辺列車全駅券**の組み合わせ。行きはカプセル、帰りは列車という動線が前提の商品です。

|---|---|
| 1 | 08:30〜09:00 |
| 2〜18 | 09:00から30分ごと |

最終入場の時間を過ぎると入れません。週末・祝日や点検があると乗車が遅れることがあり、予約時刻から30分以上遅れると乗れないことがあります（返金なし）。

## 予約と当日券、どっちにする？

**結論：スカイカプセルはネット予約。海辺列車も予約が無難ですが、当日券はあります。** 公式の予約案内に書いてあることです。

| | 内容 |
|---|---|
| 発売 | **毎週火曜日 07:00（韓国時間）**、4週間後の1週間分（月〜日） |
| 予約先 | 公式サイト [bluelinepark.com/booking.do](https://www.bluelinepark.com/booking.do)（韓国語・英語・中国語ページあり） |
| チケット | カカオトークかメールでモバイルチケットが届く。QRコードが乗車券、バーコードが駐車割引券 |
| 当日券 | ネットとは別枠で**少量**を窓口で先着販売。早めに売り切れることがある |
| 割引 | 窓口購入のみ、身分証が必要 |
| 変更 | 不可。キャンセルして取り直す |

## 尾浦発と青沙浦発、どっちから乗る？

| | 尾浦駅（미포정거장） | 青沙浦駅（청사포정거장） |
|---|---|---|
| 住所 | 海雲台区タルマジキル62番キル13 | 海雲台区青沙浦路116 |
| 最寄り駅 | 地下鉄2号線**中洞（チュンドン）駅7番出口**から約800m、徒歩10〜15分 | なし。マウルバス2・7・10番「ブルーラインパーク」下車 |
| 海雲台ビーチから | ビーチの東端にそのまま続く | 列車かカプセルで移動 |
| 駐車場 | ブルーラインパーク尾浦駐車場（タワー式） | **専用駐車場なし** |
| カプセルの向き | 尾浦 → 青沙浦 | 青沙浦 → 尾浦 |

**海はどっち側の窓に見える？** 公式の路線図と地図を見ると、線路は海岸に沿って東へ延び、海は南側です。つまり**尾浦から青沙浦へ向かうときは進行方向の右、青沙浦から尾浦へ戻るときは左**が海。日は西（海雲台ビーチ、マリンシティの高層ビルの方向）に沈むので、**夕日を正面寄りに見たいなら青沙浦 → 尾浦方向**です。これは路線図から読んだ一般的なコツで、公式のおすすめではありません。座席の向きや実際の見え方は天気やカプセル次第です。

## 往復コース：カプセル片道＋列車片道

公式パッケージ（カプセル片道＋列車全駅券）がそのままこの形です。予約画面で**出発地（尾浦・青沙浦・松亭）**と**先に乗る施設**を選びます。

1. **尾浦駅**でスカイカプセルに乗る。約30分で**青沙浦駅**に着く。
2. 青沙浦から海辺列車（全駅券）で**タリットル展望台、九徳浦、松亭**まで行き、折り返して尾浦方面へ戻る。全駅券は各駅で1回ずつ降りられます。
3. 逆回りも可能。青沙浦からカプセルで尾浦に戻る（パッケージでカプセルの乗車駅を青沙浦にする）。

松亭から始める場合、松亭にカプセルはないので、公式案内では「先に乗る施設」として海辺列車を選ぶように書かれています。カプセルの待ち時間が長引くと最終列車に間に合わないことがある、という注意書きもあるので、日没前後の予定は余裕をもって組んだほうがよさそうです。

## 11〜12月の日没時刻に合わせる

韓国天文研究院の「月別 日・月 出没時刻」（釜山、暦書ベース）の日没時刻です。冬のカプセル最終入場（17:30〜18:00）と見比べてください。

| 日付 | 釜山の日没 |
|---|---|
| 11月24日 | 17:13 |
| 11月30日 | 17:12 |
| 12月3〜8日 | 17:11（1年で最も早い時期） |
| 12月15日 | 17:13 |
| 12月24日 | 17:17 |
| 12月31日 | 17:21 |

- カプセルから夕日を見るなら、**16:30〜17:00か17:00〜17:30の入場枠**が日没（17:11〜17:21）に重なります。片道約30分なので、入場してすぐ乗れれば、日が沈む間は海の上です。
- **海辺列車は日没後も19:00まで**走るので、暗くなった海を見るコースもできます。
- 日没時刻は水平線基準です。タルマジ側の地形や天気で、実際に見える時刻は変わります。

## 一般的なコツ

公式ページに書いてあることだけをまとめました。

- **火曜の朝7時（韓国時間）を覚えておく。** 4週間後の1週間分がまとめて開きます。行きたい日が決まっているなら、その4週間前の火曜日が予約日です。
- **スカイカプセルは時間指定のチケット。** 30分以上遅れると乗れず、返金もありません。海雲台駅から尾浦まで、バスと徒歩で20分ほど見ておくと安心です。
- **海辺列車は最初の乗車時刻だけ守ればよい。** 再乗車は到着順、青沙浦と簡易駅は先着入場なので、混む日は待ちます。
- **荷物はロッカーへ。** 尾浦・青沙浦・松亭にロッカーがあります（小2,000・中3,000・大5,000ウォン）。機内持ち込みサイズのスーツケースは乗せられますが、大きな荷物は断られることがあります。
- **ベビーカーは畳んで、ペットはキャリーに。** 手動車いすは海辺列車にそのまま乗れ、スカイカプセルは畳んで移動。電動車いすはどちらも不可です。
- **おむつ替え台**は尾浦駅・青沙浦駅の2階女子トイレと、松亭駅切符売り場前の女子トイレにあります。
- **雨でも走ります。** 大雨・台風のときは止まることがあるので、お知らせを見てから出かけてください。
- カプセル内の冷暖房、座席の向き、待ち時間の目安は公式に数字がないので書いていません。

### スカイカプセルは予約なしで当日買えますか？

窓口で少量の当日券を先着販売していますが、早めに売り切れることがあると公式に書かれています。確実に乗るなら火曜7時の発売で予約してください。

### スカイカプセルの料金は1人分ですか？

いいえ、**1台分**です。2人乗り50,000ウォン、3人乗り55,000ウォン、4人乗り60,000ウォン。カプセルの中の広さはどれも同じです。

### 海辺列車の往復はいくら？

1回券は片道なので、往復なら2回券（14,000ウォン）か全駅券（16,000ウォン）が必要です。子どもはそれぞれ11,000・13,000ウォンです。

### 冬の最終は何時？

スカイカプセルは17:30〜18:00の入場が最終枠。海辺列車は尾浦・松亭発の最終が19:00、青沙浦発は19:09（松亭行き）と19:12（尾浦行き）で、最終の10分前に発券が終わります。

### 尾浦と青沙浦、どちらから乗るのがいい？

地下鉄で行きやすいのは尾浦（中洞駅7番出口から徒歩10〜15分）。夕日なら、西へ向かう青沙浦 → 尾浦方向が正面寄りになります（路線図から読んだ一般的なコツです）。

### 11月下旬〜12月の釜山の日没は何時？

韓国天文研究院の表で、11月24日17:13、12月3〜8日17:11、12月24日17:17、12月31日17:21です。

### VISIT BUSAN PASSで乗れますか？

今回、公式資料では確認できませんでした。[VISIT BUSAN PASS公式サイト](https://www.visitbusanpass.com/)の施設一覧で確認してください。

### 5人で1台に乗れますか？

基本は4人まで。7歳以下（2020年生まれ以降）が1人含まれる5人だけ4人乗りに乗れます。それ以外は2人乗り＋3人乗りに分けます。
