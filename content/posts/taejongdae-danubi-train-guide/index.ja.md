**太宗台（태종대、テジョンデ）は入場無料です。ダヌビ列車（다누비열차）はいま安全点検で運休していて、代わりに無料の循環バスが水曜から日曜の09:30〜17:30に走っています。月曜と火曜はバスも休みです。** 釜山駅（부산역）からは17・88・101番バスで40分ほど、南浦洞（남포동、ナンポドン）からは30分ほどです。以下の内容は、ダヌビ列車を運営する釜山観光公社と、遊園地を管理する釜山施設公団のサイトを2026年11月28日に確認したものです。

## 太宗台ダヌビ列車、いま乗れる？

乗れません。釜山観光公社の案内に「ダヌビ列車は現在、安全点検のため運行していません」とあり、再開の時期は「安全点検の終了時まで」としか書かれていません。その間は無料の循環バスが同じ道を回っています。

## 太宗台 無料循環バスの乗り方

| 項目 | 内容 |
|---|---|
| 料金 | 無料 |
| 運行する曜日 | 水曜から日曜 |
| 休み | 毎週月・火曜（連休は変わることあり） |
| 乗車券の配布時間 | 09:10〜17:30 |
| 運行時間 | 09:30〜17:30 |
| 車両 | 30人乗り1台、46人乗り2台 |
| 乗り場 | ダヌビ広場のチケット売り場（다누비광장 매표소） |

チケット売り場で便ごとの無料乗車券をもらって乗ります。先着順なので、席が埋まったらその便は締め切りです。売り場と乗り場は、正門の観光案内所から200mほど坂を上ったところにあります。

路線は一方向に回る循環です。

1. **ダヌビ広場（다누비광장）**：出発
2. **展望台（전망대）**（1.7km）
3. **影島灯台（영도등대）**（200m）
4. **太宗寺（태종사）**（600m）
5. **ダヌビ広場**：到着（1.3km）

どの停留所でも自由に乗り降りできます。雨や台風など天気の悪い日はバスが止まります。週末の午後は乗車券がすぐなくなるので、着いたらまず売り場に寄ってください。月曜か火曜に行くなら、最初から歩くつもりでスニーカーを履いていくのが正解です。展望台と灯台の間は200mなので、ここはどのみち歩いたほうが早いです。

## 太宗台の入場料と開放時間

入場料はかかりません。2006年9月1日に無料になり、そのときから一般の車は入れなくなって、ダヌビ列車が走りはじめました。

| 時期 | 入れる時刻 | 出ないといけない時刻 |
|---|---|---|
| 11〜2月 | 05:00 | 24:00 |
| 3〜10月 | 04:00 | 24:00 |

循環道路は夜12時まで歩けますが、灯台の下の玉砂利の浜（자갈마당）のような海辺は、軍の作戦のため夜8時ごろから立ち入れなくなります。冬は日が沈むのが早いです。12月3日から8日の釜山の日の入りは17:11（韓国天文研究院、2026年11月11日確認）。海の色まで見たいなら、午後3時前には正門に着いておいてください。

## 何がある？回る順番

太宗台は影島（영도、ヨンド）の南の端にある、広さ1,632,809㎡の遊園地です。2005年11月1日に名勝第17号に指定され、2013年12月6日には国家地質公園に認定されています。循環バスの停留所の順に見ていけば大丈夫です。

{{< figure src="taejongdae-yeongdo-lighthouse.jpg" alt="断崖の上の白い影島灯台と海洋文化空間の建物、下へ続く階段の道" caption="影島灯台の海洋文化空間。室内の展示は毎週月曜が休み（釜山施設公団の案内）（2014年5月）・写真：韓国観光公社 フォトコリア、キム・ジホ・公共ヌリ第1類型" >}}

- **展望台（전망대）**：循環道路の真ん中あたり、断崖の上にあります。近くに五六島（오륙도、オリュクド）、晴れた日には約56km先の対馬まで見えます。展望台の休憩所の売店は臨時休業中です。
- **影島灯台（영도등대）**：1906年12月に初めて灯がともった灯台です。2004年にギャラリー、図書室、映像館、自然史展示室のある海洋文化空間に変わりました。室内は月曜、1月1日、旧正月と秋夕（チュソク）の当日が休み。10時から17時の間に行けば開いています。問い合わせは051-405-1201。
- **神仙岩と望夫石（신선바위·망부석）**：灯台の下の岩ですが、落石の危険があるため今は立ち入りできません。上から見下ろすだけで我慢することになります。
- **太宗寺（태종사）**：循環道路沿いのお寺です。前に無人のコンビニがあります。
- **遊覧船**：船着き場を出て、太宗台の沖と五六島の近くまで約40分かけて回ります。料金と時間は船着き場ごとに違うので、乗る前に電話で聞いてください（灯台遊覧船、등대유람선 051-405-3434）。

灯台まで下りる道は階段が長いです。下りた分だけまた上ることになるので、ひざの悪い人が一緒なら展望台まで見て引き返すほうがいいです。

## 太宗台への行き方

地下鉄の駅がないので、バスに乗ることになります。公団が案内している路線と所要時間です。

| 出発地 | 乗り場・バス | 所要時間 |
|---|---|---|
| 釜山駅（부산역） | 7番出口 → 教元ビル（교원빌딩）の向かいから17・88・101番 | 約40分 |
| 南浦洞（남포동） | 南浦駅（남포역）6番出口 → ロッテ百貨店（롯데백화점）の向かいから8・17・30・88・186番 | 約30分 |
| 西面（서면、ソミョン） | ジュディス太和（쥬디스태화）の向かいから88番 | 約1時間 |
| 広安里（クァンアリ） | 41・42番 → 門峴交差点（문현교차로）で101番に乗り換え | 約1時間16分 |
| 海雲台（ヘウンデ） | 1003番 → 中央洞（중앙동）で88番に乗り換え | 約1時間21分 |

降りるのは「太宗台（태종대）」か、終点の「太宗台温泉（태종대온천）」のバス停です。海雲台からは1時間以上かかるので、南浦洞やチャガルチ（자갈치）と同じ日にまとめるのがおすすめです。地下鉄の料金と乗り換えは[釜山の地下鉄の乗り方]({{< relref "/posts/busan-metro-guide" >}})にまとめてあります。

## 太宗台の駐車場

駐車場は24時間開いていて、支払いはカードだけです。

| 駐車場 | 台数 | 備考 |
|---|---|---|
| 第7駐車場（제7주차장） | 399台 | 乗用車 |
| 第7駐車場-2（제7주차장-2） | 144台 | 乗用車 |
| 自由ランド駐車場（자유랜드 주차장） | 114台 | |
| 正門入口駐車場（정문입구 주차장） | 26台 | バス専用 |

| 車両 | 最初の1時間 | 以降10分ごと |
|---|---|---|
| 小型（15人乗り未満） | 1,000ウォン | 200ウォン |
| 中型（25人乗り未満） | 1,500ウォン | 300ウォン |
| 大型（25人乗り以上） | 2,000ウォン | 400ウォン |

料金は釜山施設公団の「よくある質問」によるものです。軽自動車、多子世帯、エコカーは50%引き。乗用車で3時間いても3,400ウォンなので、駐車料金の負担は小さいです。ただ、遊園地の中の循環道路は昼間、一般の車が入れません。昼に入れるのは交通弱者の車だけで1台2,000ウォン、夜間の車両開放も1台2,000ウォンです。入れる時刻は釜山観光公社の051-405-8745に聞いてください。

## ちょっとしたコツ

- **水曜から日曜の間に行ってください。** 月・火曜は循環バスがないので、4.3kmを全部歩くことになります。
- **荷物は正門で預けてください。** 管理事務棟1階のコンビニの左にコインロッカーがあります。大型1,000ウォン、小型500ウォンで、カードしか使えません。
- **ベビーカーと車いすは無料で借りられます。** 正門の観光案内センターで10:00から17:00まで、身分証が必要です。24か月未満の子ども連れか、歩くのが不自由な人が対象。雨、雪、強風の日は貸し出していません。
- **犬**はリードとフン袋を持っていけば入れます。ダヌビ列車には一緒に乗れません。
- **日の出**は影島灯台と展望台から見ます。冬は05:00から入れて、12月31日の釜山の日の出は07:32です（韓国天文研究院、2026年11月11日確認）。断崖の上で風が強いので、[釜山の12月の服装の記事]({{< relref "/posts/busan-december-what-to-wear" >}})を見て着込んでいってください。
- 同じ日に[松島海上ケーブルカー]({{< relref "/posts/songdo-cable-car-guide" >}})を組み合わせれば、影島と松島の海を1日で両方見られます。

## よくある質問

### 太宗台に入場料はありますか？

ありません。2006年9月から無料です。お金がかかるのは駐車料金くらいです。

### ダヌビ列車はいつ再開しますか？

釜山観光公社の案内には「安全点検の終了時まで」休むとしか書かれていません。行く前の日に051-405-8745へ電話すれば、その日に何が走っているかすぐわかります。

### 循環バスは有料ですか？

無料です。チケット売り場で無料の乗車券をもらって乗ります。先着順です。

### 月曜に行っても大丈夫ですか？

遊園地は開いています。ただ、循環バスと影島灯台の室内展示が休みの日なので、歩いて1周するつもりで行ってください。

### 歩いて1周できますか？

できます。循環道路は4.3kmで、夜12時まで歩けます。
